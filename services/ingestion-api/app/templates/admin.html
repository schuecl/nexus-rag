Portal settings

Requires the rag-admin role. Note what that role does not grant: no document access, no query, no curation — managing the vocabulary a document is tagged from is a different authority from seeing anything tagged with it.

Classification banner

Shown at the top and bottom of every portal page. It states what this system is accredited to hold — a deployment decision, not a per-user one, so the same page carries the same marking for everyone.

The full marking line as your accreditation words it. Leave empty and save to remove the banner — pages then read No label set rather than falling back to UNCLASSIFIED, which is a real marking meaning “reviewed and found releasable”.

CAPCO register colours. An unrecognised value renders neutral rather than guessing — a wrong colour on a marking is worse than no colour.

Portal theme

Applies to everyone. Deliberately not a per-user preference: two people looking at the same classified record should see the same page, and the classification banner's colours in particular must mean the same thing to every viewer.

Themes change the palette only. CAPCO banner colours and the good/degraded/failed status colours are fixed in every theme — they carry meaning, so they are not a matter of taste.
